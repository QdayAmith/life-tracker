# Life Tracker CLI App

A command-line app to track your expenses, habits, and live crypto prices — built with Python.

## Features
- Track and categorize your expenses
- Track daily habits and monitor streaks
- Fetch live cryptocurrency prices via CoinGecko API

## How to Run

1. Clone the repo
2. Create a virtual environment: `python -m venv venv`
3. Activate: `venv\Scripts\activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run: `python main.py`

## Built With
- Python
- CoinGecko API
